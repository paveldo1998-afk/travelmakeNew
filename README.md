# Travel Finance (GitHub Pages)

Веб-прототип учёта денег в поездке в духе CoinKeeper.

**Демо:** https://paveldo1998-afk.github.io/travelmakeNew/

## Как пользоваться

1. Создайте поездку (например «Япония», 100 000 ¥, с собой 10 000).
2. На экране поездки **удерживайте счёт** → введите сумму.
3. **Перетащите монету** (или нажмите) на категорию — расход, на другой счёт — перевод.
4. Откройте **Статистика** — остатки и разбивка по категориям.

Данные хранятся локально в `localStorage` браузера.
