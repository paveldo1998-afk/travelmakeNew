# TravelOrganizer

Мультитул для путешественников в дизайне «Сигнал»: сборы, план дня, документы и учёт наличных.

**Сайт:** https://paveldo1998-afk.github.io/travelmakeNew/

## Возможности

- **Поездка** — закреплённые материалы, ближайший день, прогресс сборов
- **Сборы** — вещи по состояниям (ещё нет / дома / упаковано), шаблоны, задачи
- **План** — события и задачи по дням
- **Документы** — локальные записи, закрепление «под рукой»
- **Деньги** — счета и категории расходов (удержание → сумма → перетаскивание)

Данные хранятся в `localStorage` браузера. Есть светлая и тёмная тема.
