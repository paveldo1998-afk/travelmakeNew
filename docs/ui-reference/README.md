# Утверждённый визуальный источник TravelOrganizer PWA

Исходное изображение предоставлено владельцем в текущей беседе. Оно скопировано без изменения байтов в `approved-travel-reference.png`. В `panels/` находятся восемь его фрагментов, обрезанных по экранам; они не перерисованы и не улучшены генеративно. Координаты, размеры и SHA256 приведены в `manifest.json`.

Верхний ряд слева направо: список поездок, обзор поездки, вещи, план дня. Нижний ряд: документы, задачи, обсуждения, бюджет.

Фрагменты — визуальные ориентиры для создания настоящих компонентов, а не готовые фоновые изображения приложения. Рамки телефонов, вырезы, внешние украшения коллажа и дефекты мелкого текста не копируются в интерфейс. Увеличение фрагмента не восстановит несуществующую детализацию. Названия и даты локализуются, состояния вещей и аудитории файлов реализуются по заданию.

Полное задание находится в корне комплекта: [CODEX_PWA_TASK_RU.txt](../../CODEX_PWA_TASK_RU.txt).

Архив не содержит установщиков, исполняемых сценариев или файлов шрифтов. В нём нет кода новой PWA: это комплект постановки задачи Codex.
