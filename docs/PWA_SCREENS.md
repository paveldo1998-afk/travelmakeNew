# TravelOrganizer PWA — экраны, переходы и статусы

Состояние на 30 октября 2026 года. Последнее указание владельца разрешило завершить приложение без Figma. Код текущего клиента реализован; историческая Figma-версия в `design-review` остаётся черновиком и не задаёт блокировку этой работы.

Здесь **локально** означает настоящую операцию с IndexedDB/Blob или настройкой данного браузера. **Демо** означает отдельную синтетическую базу. **Интерфейс ограничения** показывает недоступность функции без имитации успешного сервера. Подключённых серверных функций в этой версии нет.

## Основные восемь экранов

Маршруты работают под `/travelmakeNew/` через hash без server rewrite. `:tripId` и `:id` — сохранённые идентификаторы объектов.

| Экран | Маршрут и основные переходы | Фактический статус | Снимок браузера |
| --- | --- | --- | --- |
| Мои поездки | `#/trips` → обзор, создание, архив, профиль; `?q=…` | Локально: список, поиск, создание, редактирование, архив/удаление; реальные открытые даты и вычисленный срок | [01](browser-checks/main/01-trips.png) |
| Обзор поездки | `#/trip/:tripId/overview` → шесть действий, участники, контакты, история, закрепления | Локально: обложка, данные, счётчики, навигация; приглашение объясняет отсутствие сервера | [02](browser-checks/main/02-overview.png) |
| Вещи / сборы | `#/trip/:tripId/packing?state=home&q=…&assignee=…` → вещь, шаблоны, задачи | Локально: три состояния, категории, CRUD, поиск/фильтры; обычный выбор и дополнительный перенос с отменой | [03](browser-checks/main/03-packing.png) |
| План дня | `#/trip/:tripId/plan?day=YYYY-MM-DD`; `?undated=1` → событие, карта | Локально: выбранный день, события, детали, дата по желанию; погода/маршруты/статус рейса не подключены | [04](browser-checks/main/04-plan.png) |
| Документы | `#/trip/:tripId/documents` → запись, загрузка, просмотр, закрепление | Локально: метаданные и реальные файлы отдельно, поиск/категории, удаление копии или документа; серверные ACL не подключены | [05](browser-checks/main/05-documents.png) |
| Задачи | `#/trip/:tripId/tasks` → задача, календарь | Локально: CRUD, выполнение, этап/срок/ответственный, задачи без срока; настройка напоминания без фоновой доставки | [06](browser-checks/main/06-tasks.png) |
| Обсуждения | `#/trip/:tripId/discussions`; контекст объекта в query | В локальном режиме — интерфейс ограничения. В демо сообщения/голосование сохраняются только в синтетической базе | [07 · демо](browser-checks/main/07-discussions.png) |
| Бюджет | `#/trip/:tripId/budget` → расходы, счета, переводы, история, распределение | Локально: план/факт/остаток, точные суммы и ручной FX; совместная книга долгов не подключена | [08](browser-checks/main/08-budget.png) |

Глобальная навигация: **Поездки · Архив · Создать · Профиль**. Внутри поездки постоянно доступны **Поездка · Сборы · План · Документы · Обсуждения**. Бюджет и задачи имеют отдельные именованные входы из обзора. Back/reload сохраняют контекст выбранного дня и hash-фильтров; изменённый ввод защищён диалогом.

## Формы, подробности и дополнительные сценарии

Редакторы открываются как настоящие доступные диалоги поверх текущего контекста. Отдельный маршрут для каждого поля не создаётся. ID существующего объекта сохраняется при правке.

| Экран / вход | Действия и данные | Статус |
| --- | --- | --- |
| Создание / изменение поездки | Название, открытые даты, направления, обложка по желанию, описание, валюта; диапазон дат проверяется; финансовая валюта не меняется молча | Локально |
| Архив `#/archive` | Завершённые и архивированные поездки, открытие; архивирование с обзора | Локально |
| Подробности вещи `…/item/:id` | Количество, категория, одно из трёх состояний, локальный ответственный, заметка/ссылка, задача, доступные метаданные создания | Локально |
| Редактор вещи и выбор состояния | Обязательные поля, количество/URL, три явные цели, безопасная отмена; нет четвёртого «готово» | Локально |
| Удержание/перенос вещи | Видимые «Ещё нет / Дома / Упаковано», Escape/отмена, сохранение после выбора цели | Локально; обычная кнопка остаётся доступна |
| Шаблоны `#/templates`, `#/template/:id` | Именованные наборы, состав, правка, копирование, удаление | Локально |
| Применение шаблона | Подтверждение с поездкой и числом позиций; независимые новые ID и `missing` | Локально |
| Подробности события `…/event/:id` | Дата/время либо «День не назначен», категория, фото по желанию, адрес, контакт, заметка, документ | Локально |
| Редактор события | Назначение и очистка дня, времени/зоны и связи с документом без нового ID | Локально |
| Идеи без дня `…/plan?undated=1` | Отдельный список и последующее назначение дня прежнему событию | Локально |
| Карта `…/map` | Сохранённые адреса и входы в события/контакты; ясное объяснение отсутствия карты | Список локально; карта/трекинг/офлайн-карта не подключены |
| Загрузка документа | Настоящий PDF/PNG/JPEG/WebP до 10 МБ, сигнатура/тип/размер, название/категория/связь; транзакция метаданных и байтов | Локально |
| Просмотр `…/document/:id` | Настоящий Blob через PDF iframe/изображение, реквизиты и отдельные признаки аудитории/копии | Локально |
| Права документа | Кнопка объясняет отсутствие серверного ACL; изменение локальной метки не даёт доступ другому человеку | Интерфейс ограничения |
| Удаление локальной копии | Явное предупреждение; метаданные сохраняются, повторное открытие требует реальных байтов | Локально |
| Удаление документа | Отдельное подтверждение; удаление записи/соответствующего Blob и очистка связей без удаления другого события | Локально |
| Подробности задачи `…/task/:id` | Выполнение, срок или отсутствие срока, время/зона, этап, локальный ответственный, описание и связь с вещью | Локально |
| Редактор задачи | Один параметр напоминания, проверка даты/времени, без автоматического срока; покупка не меняет упаковку | Локально; фоновая доставка не подключена |
| Календарь подготовки `…/calendar?month=YYYY-MM&day=…` | Месяцы до/после поездки, выбор даты, задачи месяца и вход в список без срока | Локально |
| Уведомления `#/settings` | Явный запрос разрешения после объяснения; отображение отказа и ограничения закрытого приложения | Разрешение браузера локально; push/планировщик не подключены |
| Участники `…/participants` | Локальные имена/демоперсоны различимы с аккаунтами; описание будущих ролей | Список локально; роли/приглашения/исключение не подключены |
| Приглашение `…/invitation?state=expired` или глобальное `#/invitation/expired` | Состояния «не подключено / истекло / отозвано / доступ отозван» явно представлены как справка будущей функции | Интерфейс ограничения; рабочая ссылка не создаётся |
| Контакты `…/contacts`, `…/contact/:id` | Каталог, создание/правка/удаление, телефон, копирование адреса, ссылка и заметка | Локально |
| История `…/history` | Журнал записанных клиентом действий с автором «На этом устройстве» и временем; просмотр не добавляет действия | Локально; серверный аудит не подключён |
| Редактор расхода | Сумма/валюта, категория, счёт, дата, личные метки плательщика/участников, заметка и документ | Локально; личные метки не становятся общими долгами |
| Расход другой валюты | Явно введённые курс и дата; исходная сумма плюс точная сумма в валюте поездки; неявное округление отклоняется | Локально; автоматический источник курсов не подключён |
| Перевод | Счёт-источник/получатель, сумма, дата, заметка; расход не увеличивается | Локально |
| Удержание денежного счёта | Перенос на счёт/категорию открывает предзаполненную форму; раннего изменения денег нет | Локально; обычные кнопки обязательны и доступны |
| Счета `…/accounts` | Текущие остатки, создание/правка/сверка; «С собой» и «В номере» сохраняются | Локально |
| История финансов `…/transactions` | Расходы и переводы; отмена проверяет остатки и возвращает соответствующие суммы | Локально |
| Распределение `…/settlements` | Входы в равные/заданные доли, баланс и погашение с ясным ограничением | Общая серверная книга и расчёты не реализованы |
| Профиль `#/profile` | Аккаунт не подключён, вход объясняет необходимость сервера, переходы к настройкам/данным/демо | Локальный режим разработки; настоящего входа нет |
| Настройки `#/settings` | Светлая/тёмная/системная тема, русский язык, уведомления, установка, проверка обновлений | Настройки локально; другие языки не подключены |
| Хранилище `#/storage` | Копии, объём/квота origin, экспорт с байтами, безопасный импорт и очистка выбранной базы | Локально |
| Пустые списки и поиск без результатов | Объяснение и подходящее действие; пользовательские записи не заменяются примером | Локально |
| Загрузка и отказ хранилища | Индикатор реального сохранения; форма/первая ошибка остаются, ложного успеха нет | Локально |
| Конфликт вкладок | Отклонение устаревшей ревизии; сравнение полей/последствий; явное принятие актуальной базы с сохранением ввода | Локально |
| Ожидающая отправка / отзыв / серверный конфликт `#/states?state=…` | Справочный интерфейс; не создаёт фиктивную очередь, ошибку или серверное действие | Сервер не подключён |
| Обновление | Реальная waiting-версия SW; сохранить ввод или явно отказаться, затем обновить | Локальная PWA-функция |

Снимки дополнительных представлений находятся в [browser-checks/extra](browser-checks/extra/), реальные действия и ошибки — в [browser-checks/scenarios](browser-checks/scenarios/). Например: [редактор вещи](browser-checks/scenarios/item-editor.png), [загрузка документа](browser-checks/scenarios/document-upload-form.png), [дата события с тем же ID](browser-checks/scenarios/event-date-assignment-same-id.png), [конфликт вкладок](browser-checks/scenarios/cross-tab-conflict-field-comparison.png), [ожидание обновления с вводом](browser-checks/scenarios/update-waiting-dirty-form-preserved.png).

## Архитектура данных и границы

`app.js` загружает `js/controller.js`. Представления и общие элементы находятся в `views.js/shared.js`, формы — в `forms.js`, дополнительные жесты — в `gestures.js`, предметные операции — в `domain.js`, транзакционное хранилище — в `storage.js`, PWA lifecycle — в `pwa.js/sw.js`.

Логическая версия данных — 2, версия схемы IndexedDB — 1. Основная база `travelorganizer.pwa.v2` и демобаза `travelorganizer.pwa.v2.demo` имеют stores `state`, `files`, `meta`. Ключ файла составной `[tripId, docId]`: одинаковый ID документа в разных старых поездках не смешивает содержимое.

Миграция сохраняет исходный JSON прежнего ключа и метаданные результата. Текущий остаток счёта не пересчитывается повторным применением старых операций. Точные десятичные поля и минимальные единицы добавляются без округления старых значений; более точная историческая дробь сохраняется. Записи и Blob-файлы изменяются одной транзакцией. Конфликт/отказ записи не превращается в успешное сохранение.

## Контракты будущих адаптеров

Это описание границ интеграции, а не существующий сервер или SDK. Конкретный протокол и hosting выбираются отдельной задачей; секреты и токены не помещаются в статические assets.

| Адаптер | Необходимые операции и подтверждения |
| --- | --- |
| Auth | `getSession/signIn/signOut`; подтверждённый сервером user ID, срок сессии, OAuth-проверка Google/Apple; локальное имя не заменяет сессию |
| Collaboration | `listMembers/createInvite/acceptInvite/revokeInvite/removeMember`; роли, срок/отзыв и последствия проверяются сервером |
| Documents | `upload/getMetadata/getDownloadGrant/setAudience`; ACL перед выдачей содержимого, версия прав и отдельная политика локальных копий/отзыва |
| Discussion | `listMessages/sendMessage/react/vote`; server IDs, автор/время, идемпотентность и проверка доступа ко всем карточкам объектов |
| Sync | `pull(cursor)/push(mutations,baseRevision,idempotencyKey)`; подтверждение отправки, очередь, полевая модель конфликтов и отзыва; сейчас локальная очередь сервера отсутствует |
| Push | `subscribe/schedule/cancel`; явное разрешение, привязка пользователя/устройства и одной настройки задачи с датой/зоной |
| Maps | Геокодирование, реальные координаты/точки и маршруты с источником; офлайн-карта требует самостоятельной реализации |
| Rates | Курс валют с базой, датой/временем и источником; ручной датированный курс уже доступен локально |
| Settlements | Распределение расхода, общие балансы, погашение и серверная общая книга без двойного учёта расхода |

Ни один из этих интерфейсов не даёт действующих серверных прав, пока адаптер и подтверждение сервера отсутствуют.
